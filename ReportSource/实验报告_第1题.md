## 一、实验目的

1. 掌握 Bash 中处理含空格文件名的方法（引号、转义）

3. 掌握 `chmod` 设置目录与文件权限的精确操作
4. 熟悉 `find -printf` 统计文件字节数并生成清单

### 步骤4：复制 input 下所有 .txt 文件到 work/25020007191/，保留相对目录结构

使用 `find ... -exec cp --parents` 保留相对路径，自动处理文件名中的空格：

```bash
mkdir -p ~/q01/work/25020007191
cd ~/q01/input && find . -name '*.txt' -exec cp --parents {} ~/q01/work/25020007191/ \;
```

**输出结果：**
```
（无输出，命令执行成功）
```

验证复制结果：

```bash

ls -laR ~/q01/work/25020007191
```

> **说明：** `find . -name '*.txt'` 匹配所有以 `.txt` 结尾的文件（含隐藏文件 `.secret.txt`）。`--parents` 使 `cp` 保留 `./docs/...`、`./tmp/...` 的相对路径结构，`find -exec` 保证文件名含空格时亦能正确传递参数。

### 步骤5：设置复制后目录权限为 750，文件权限为 640

```bash
find ~/q01/work/25020007191 -type d -exec chmod 750 {} +
find ~/q01/work/25020007191 -type f -exec chmod 640 {} +
ls -laR ~/q01/work/25020007191
```

**输出结果：**

## 四、实验结果

### 4.1 结果展示

`inventory.txt` 列出了所有复制到 `work/25020007191/` 的文件及其字节数：

```
docs/notes one.txt 11
docs/.secret.txt 7
tmp/empty.txt 0
```

目录权限为 `750`，文件权限为 `640`，目录结构与 `input/` 完全一致。

### 4.2 结果分析

1. `input/docs/run.log` 不是 `.txt` 文件，不被复制，符合要求。
2. `.secret.txt` 虽为隐藏文件（以 `.` 开头），但以 `.txt` 结尾，仍属于 `.txt` 文件，被正确复制到 `work/25020007191/docs/`。
3. `notes one.txt` 含空格，`find -exec cp --parents` 通过花括号 `{}` 传递参数，无需担心文件名拆分。
4. `empty.txt` 字节数为 0，验证正确。
5. `inventory.txt` 通过 `find . -type f ! -name inventory.txt` 排除自身，内容准确。

## 五、实验总结

通过本次实验，我掌握了以下技能：

1. 使用引号和 `\` 正确处理文件名中的空格
2. `find ... -exec cp --parents` 保留相对目录结构复制文件的技巧
3. 通过 `find -type d -exec chmod` 精确设置目录权限，`find -type f -exec chmod` 设置文件权限
4. `find -printf '%P %s\n'` 统计复制文件的相对路径与字节数并生成清单
