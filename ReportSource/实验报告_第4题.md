### 步骤2：创建 report.tex 并补全内容

在 `~/q04` 创建 `report.tex`，按题目模板补全：加入带编号和 `label` 的公式、2×2 表格（带 `caption` 和 `label`），并在正文中使用 `\eqref`/`\ref` 引用：

```latex
\documentclass{article}
\usepackage{amsmath}
\usepackage{booktabs}
\usepackage[UTF8]{ctex}
\begin{document}
\title{Tool Report}
\author{周御基 --- 25020007191}
\maketitle
\section{Result}

我们在此给出模型使用的线性函数。设输入为 $x$，输出为 $y$，则
\begin{equation}
  y = w x + b,
  \label{eq:linear}
\end{equation}
其中 $w$ 是权重（weight），$b$ 是偏置（bias）。公式~\eqref{eq:linear} 表明
``输出是输入的线性变换''。

观测到的两组数据如表~\ref{tab:data} 所示。

\begin{table}[htbp]
  \centering
  \begin{tabular}{cc}
    \toprule
    $x$ & $y$ \\
    \midrule
    1 & 5 \\
    2 & 9 \\
    \bottomrule
  \end{tabular}
  \caption{示例数据}
  \label{tab:data}
\end{table}

表~\ref{tab:data} 中的数据说明了输入与输出之间的对应关系。

\end{document}
```

### 步骤3：先用 pdflatex 编译（记录错误与解决方案）

```bash
cd ~/q04 && latexmk -pdf -halt-on-error report.tex
```

**输出结果（错误节选）：**
```
! LaTeX Error: Unicode character 周 (U+5468)
               not set up for use with LaTeX.

! Critical Package ctex Error: CTeX fontset `ubuntu' is unavailable in current
(ctex)                         mode.
```

**错误分析：** 默认编译器 `pdflatex` 对中文字符支持有限，且 `ctex` 指定 `fontset=ubuntu` 在 pdfTeX 模式下不可用。**解决方案：** 改用 `xelatex` 引擎（原生支持 UTF-8 与 CJK），并让 `ctex` 使用默认自动字体集（去掉 `fontset=ubuntu`）。

### 步骤4：使用 xelatex 引擎成功构建 PDF

```bash
cd ~/q04 && latexmk -pdf -xelatex -halt-on-error report.tex
```

**输出结果（节选，成功）：**
```
Running 'xelatex -no-pdf -halt-on-error -recorder  "report.tex"' ...
[1] (./report.aux)
Output written on report.xdv (1 page).
Latexmk: applying rule 'xdvipdfmx'...
report.xdv -> report.pdf
[1]
34542 bytes written
Latexmk: All targets (report.xdv report.pdf) are up-to-date
```

latexmk 自动运行两遍 XeLaTeX 以解析交叉引用，再由 `xdvipdfmx` 生成 `report.pdf`。

### 步骤5：验证 PDF 及交叉引用是否出现 "??"

```bash
ls -la ~/q04/report.pdf
cat ~/q04/report.aux
grep -n '??' ~/q04/report.log || echo "no-??-found"
```

**输出结果：**
```
-rw-rw-r-- 1 joe joe 34542 Aug 31 08:25 /home/joe/q04/report.pdf
\newlabel{eq:linear}{{1}{1}{}{equation.1}{}}
\newlabel{tab:data}{{1}{1}{}{table.1}{}}
（grep 未匹配到 "??"，交叉引用均已解析）
```

`report.aux` 中 `eq:linear` 解析为公式号 `1`，`tab:data` 解析为表号 `1`，无未解析的 "??"。

## 四、实验结果

### 4.1 结果展示

- 成功生成单页 PDF：`/home/joe/q04/report.pdf`（34,542 字节，PDF 1.7）
- 带编号公式：`y = w x + b`（编号 1，label `eq:linear`），正文用 `\eqref{eq:linear}` 引用
- 2×2 表格（表号 1，caption "示例数据"，label `tab:data`），正文用 `\ref{tab:data}` 引用
- 交叉引用无 "??"，输出 `report.aux` 显示两个引用均正确解析

### 4.2 结果分析

1. `latexmk -pdf -xelatex` 自动处理"运行两遍以解析交叉引用"的细节，比手动多次执行 `xelatex` 更可靠。
2. 中文内容在 ctex 宏包（配合 XeLaTeX）支持下正常显示；xelatex 原生支持 UTF-8 与 CJK，无需额外转义。
3. 生成的 PDF 可正常打开，交叉引用正确显示公式编号 (1) 与表编号 (1)。
