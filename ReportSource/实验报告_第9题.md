## 一、实验目的

1. 掌握使用 `src` 布局创建最小 Python 命令行包的方法。
2. 学会使用 `python -m build` 从源码构建 wheel。
3. 掌握在干净虚拟环境中仅从 wheel 安装并验证命令行入口。

## 二、实验环境

- 操作系统：Ubuntu 25.04（x86_64，内核 6.14.0-32-generic）
- 命令行工具：bash、python3.13、venv、pip、build 1.6.0
- 其他软件：setuptools（>=68）

## 三、实验步骤与代码

### 步骤1：创建 greetlab 包源码与 pyproject.toml

在 `~/lab/q09` 中创建 `src/greetlab/__init__.py`、`src/greetlab/cli.py` 和 `pyproject.toml`，把包名中的"学号"替换为 25020007191。

```bash
mkdir -p ~/lab/q09/src/greetlab
touch src/greetlab/__init__.py
```

`src/greetlab/cli.py`：

```python
import argparse
def main():
    p = argparse.ArgumentParser()
    p.add_argument("--name", required=True)
    a = p.parse_args()
    print(f"Hello, {a.name}!")
```

`pyproject.toml`：

```toml
[build-system]
requires = ["setuptools>=68"]
build-backend = "setuptools.build_meta"
[project]
name = "greetlab-25020007191"
version = "0.1.0"
[project.scripts]
sdt-greet = "greetlab.cli:main"
```

### 步骤2：使用 build 工具构建 wheel

```bash
cd ~/lab/q09 && ~/lab/venv/bin/python -m build
```

**输出结果：**

```

...

```

```bash
ls -la dist/
```

**输出结果：**


### 步骤3：新建干净虚拟环境，只从生成的 wheel 安装

```bash
cd ~
python3 -m venv ~/lab/q09_cleanenv
~/lab/q09_cleanenv/bin/pip install ~/lab/q09/dist/greetlab_25020007191-0.1.0-py3-none-any.whl
~/lab/q09_cleanenv/bin/pip list
```

**输出结果：**

```
Package              Version
-------------------- -------
greetlab-25020007191 0.1.0
pip                  25.0
```

### 步骤4：切到 q09 之外运行 sdt-greet

```bash
cd /tmp && ~/lab/q09_cleanenv/bin/sdt-greet --name 25020007191
```

**输出结果：**

```
Hello, 25020007191!
```

## 四、实验结果

### 4.1 结果展示

wheel 成功生成并安装到干净 venv（`pip list` 中仅有 greetlab 与 pip 自身），命令行入口 `sdt-greet` 在 q09 目录之外运行正常，输出 `Hello, 25020007191!`，退出码为 0。

### 4.2 结果分析

- `python -m build` 同时产出 sdist（.tar.gz）和 wheel（.whl），wheel 为 `py3-none-any`（纯 Python、平台无关）。
- 干净 venv 中仅安装 wheel 一个包，说明 wheel 自包含，无额外运行时依赖。
- `[project.scripts]` 生成的可执行入口 `sdt-greet` 通过 console_scripts 机制指向 `greetlab.cli:main`，验证了安装正确。
