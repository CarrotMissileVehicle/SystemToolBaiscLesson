### 步骤2：编写 analyze.sh 脚本

```bash
cat > ~/q02/analyze.sh << 'EOF'
#!/usr/bin/env bash
# analyze.sh - 第2题：随机访问日志统计
# 用法: ./analyze.sh <csv文件路径>

set -euo pipefail

if [ $# -ne 1 ]; then
    echo "usage: $0 <csv-path>" >&2
    exit 2
fi

CSV="$1"

if [ ! -f "$CSV" ]; then
    echo "error: no such file: $CSV" >&2
    exit 3
fi

echo "== top 2 paths by 5xx count =="
awk -F, 'NR>1 && $4 ~ /^5[0-9][0-9]$/ {print $3}' "$CSV" \
    | sort | uniq -c | sort -k1,1nr -k2,2 \
    | head -2 \
    | awk '{printf "%d %s\n", $1, $2}'

echo "== average latency (ms) =="
awk -F, 'NR>1 {sum += $5; n++} END { if (n>0) printf "%.2f\n", sum/n }' "$CSV"
EOF
```

脚本逻辑说明：
- **参数与存在性检查：** 接收一个 CSV 路径；`[ ! -f "$CSV" ]` 判断文件不存在时，将错误消息写入 `>&2`（stderr）并返回非零退出码 3。
- **5xx 统计：** 用 `awk -F,` 按逗号切分，跳过表头（`NR>1`），筛选第 4 列状态码匹配 `^5[0-9][0-9]$` 的记录，输出第 3 列 `path`；再经 `sort | uniq -c` 计数、`sort -k1,1nr -k2,2` 按次数降序（次数相同按 path 字典序）、`head -2` 取前 2，最后格式化输出。
- **平均值：** `awk 'NR>1 {sum+=$5; n++} END{printf "%.2f", sum/n}'` 累加第 5 列 `latency_ms` 并保留两位小数，表头不参与计算。

## 四、实验结果

### 4.1 结果展示

```
== top 2 paths by 5xx count ==
3 /api/orders
2 /api/users
== average latency (ms) ==
193.75
```

### 4.2 结果分析

1. **5xx path 统计：** 原始数据中 `/api/orders` 出现 3 次 5xx（500、502、500），`/api/users` 出现 2 次（503、500），分别排第 1、2 名；`/login` 仅 1 次，被 `head -2` 截断，符合"取前 2"的要求。
2. **平均延迟：** 全部 8 条数据 `latency_ms` 之和为 120+310+180+90+260+20+420+150 = 1550，除以 8 得 193.75，保留两位小数输出 `193.75`，结果正确。
3. **错误处理：** 对不存在的文件，错误消息写入 `stderr` 且返回非零退出码 3，符合题目要求。
